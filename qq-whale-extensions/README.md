# 小鲸鱼旧修改 · 独立扩展包

恢复来源：你提供的旧聊天《排查通用错误》，以及当时上传的 `affection(1).md`、`tools(1).md`、`prompt.md`、`app(1).md`。接口核对基线：2026-10-02 下载的 K0nd1us/QQ-agent main，package.json 版本 0.4.0，扩展 API v1。

## 安装

正式运行环境是服务器，工作笔记本仅作本地测试。默认安装位置：`%LOCALAPPDATA%\Programs\QQ Agent`。

请使用交付包 **v1.0.2 或之后的版本**。v1.0.0/v1.0.1 安装脚本在 Windows PowerShell 5.1 下读取含中文的 `package.json` 时可能乱码并报 JSON 解析错误；v1.0.2 已明确使用 UTF-8。遇到该错误时无需修改 QQ Agent 的 package.json，换本包里的安装脚本再运行即可。

1. 将安装包传到服务器，解压到 QQ Agent 安装目录之外，然后在服务器上**完全退出 QQ Agent，包括托盘**。
2. 在服务器双击本包中的 `install-server.bat`，自动使用上述路径。工作笔记本测试时使用 `install.bat` 并选择本机测试安装目录。
3. 启动 QQ Agent。在“插件”页确认 **小鲸鱼 · 隐藏关系与性格** 和 **小鲸鱼 · 创建者 /ds 命令** 已启用，在“技能”页确认 **小鲸鱼 · 关系调整与恶作剧** 已启用。

安装脚本只放入三份扩展，不覆盖 `src/app.js`、`src/tools.js`、`src/prompt.js` 或其它核心文件，不改用户配置。安装同名扩展前会备份原目录，失败会回滚。支持源码版根目录和安装版根目录；安装版的实际落点是 `resources/app/plugins` 与 `resources/app/skills`。

也可以手动复制：把本包 `plugins/whale-relations`、`plugins/whale-owner-controls` 和 `skills/whale-actions` 分别放进 QQ Agent 应用目录的对应文件夹，不要再套一层本包目录。关系插件和动作技能配套使用，创建者命令插件可单独关闭。

## 恢复的功能

- **隐藏关系温度**：每个群/私聊分别记录每个人。保留旧版评分区间、层级和慢速熟悉度增长，私聊、真实 @机器人和拍机器人增长略快。同一天消息越多，数量收益越低；光聊天不能刷过 40。
- **语境调整**：模型可调用 `whale-actions__affection_adjust`，每次最多 ±3；同人每轮最多一次，20 秒冷却。普通聊天、互损、意见不同、被纠错、被拒绝不应增减。
- **性格校准**：聪明可靠、嘴硬心软；高关系更柔软、主动、偏心，低关系疏远而不报复。关系状态只追加到本轮用户上下文末尾，不改写核心系统规则或工具协议。
- **一分钟小黑屋**：`whale-actions__mute_member` 固定禁言 60 秒；熟悉度至少 15、互动至少 5 次，目标最近 10 分钟确实发言。群级冷却 2 分钟，同人冷却 10 分钟。
- **改群名片**：`whale-actions__rename_member` 仅限上述普通熟人，无害短外号不超过 20 字。增加和小黑屋相同的冷却，保存被修改前的原始名片（包括空名片）。
- **保护**：不能操作创建者、机器人自己、管理员或群主；实时查询目标身份和机器人权限。身份或权限无法确认就不执行。创建者 QQ 默认留空，须在插件设置中填写有效 QQ 号后启用关系和管理功能；昵称、自称不参与鉴权。

恶作剧仍由模型结合语境决定，不保证它每次使用。关系分数不决定管理权限。机器人需实际具有群管理权限；工具总开关、分类开关和核心规则仍有效。接口超时也保留冷却，避免“不确定是否成功”时重复操作。

在技能设置中可单独关闭禁言、改名。关闭关系插件后，动作技能因依赖缺失停止生效；关闭动作技能后仍可保留关系增长与性格提示。

## 旧数据和更新

继续使用 QQ Agent 当前数据目录中的 `affection.json`。默认：源码版的 `data/affection.json`，安装版是 exe 旁的 `data/affection.json`；遵循 `QQ_AGENT_DATA_DIR` 和 `QQ_AGENT_PROFILE`。首次读取旧格式会保留 `affection.json.before-whale-plugin.bak`，原分数、互动次数和记录不会清零。

正式关系数据继续使用服务器当前数据目录中的 `affection.json`；默认位置为 `%LOCALAPPDATA%\Programs\QQ Agent\data\affection.json`。工作笔记本上的测试数据独立保留，不直接覆盖服务器数据。如果需要从旧备份恢复，先退出服务器 QQ Agent，备份新旧文件，确认恢复目标后再替换；已有新数据时不要直接覆盖。找不到旧文件时，创建者从 90 开始、最低 80，其他人从 0 开始。

只对扩展启用期间的新存档消息计数；首次安装/重新启用不会重算历史。后台每 2 秒检查变更存档，模型组装上下文前同步本群数据；本地消息序号去重，重启、重载和重复处理同批消息不重复涨分。自动观察不额外调用模型，不发送 QQ 消息。

关系文件不可读或损坏时停止关系插件及依赖工具，显示原因，保留原文件；不会静默清空关系。改名不会自动恢复，管理员可手动改回；旧名片位于 `affection.json` 的 `whaleExtension.cards`，禁言自动在 60 秒后解除，也可由管理员提前解除。

**把本包保存在 QQ Agent 安装目录之外。** 当前电脑的交付副本位于 `D:\project\qq-whale-extensions`，服务器应另外保留一份。当前上游安装器未保护 `plugins/skills`；服务器更新安装版后可能需要重新运行 `install-server.bat`。独立插件避免核心代码更新覆盖修改，但不保证上游未来接口永远兼容。

## 角色卡与范围

本包的性格提示根据旧聊天与旧 prompt 恢复，不冒充旧《完善版 v2》九页文档的逐字副本。现有角色卡继续使用；若旧卡强调“永远顶回去/心软不表现”，建议改为“傲是外壳、娇是底色”，避免角色卡和扩展相互拉扯。

原有拍一拍、表情包、记忆、联网等由 QQ Agent 自带工具继续提供。B 站和 QQ 空间在旧聊天中尚处于方案讨论，本包不实现它们。

### 创建者专属 /ds 命令

旧 `app.js` 里确实实现了以下命令，本包也恢复：

- `/ds ping`：回复“主人接口正常”。
- `/ds status`：回复“活着呢”。
- `/ds mute @某人` 或 `/ds mute QQ号`：固定禁言 60 秒；只认 OneBot 真实发送者 QQ 号和原始 @ 消息段，不认昵称、自称。保护创建者、机器人、群主和管理员；需要机器人有群管理权限。

这三个命令由独立 OneBot WebSocket 连接处理，读取 QQ Agent 原有 `snowluma.wsUrl/accessToken`，不另填登录态。源码版沿用应用 `ws` 依赖；Node.js 22+ 也可用原生 WebSocket。只处理既有白名单会话，服从 deny、全局/按群屏蔽；发送者命令限频、消息 ID 去重、串行处理。创建者的显式 `/ds mute` 不要求好感度门槛，也不会交给模型决定。

**当前公开插件接口不支持入站消息拦截，因此 `/ds` 仍会出现在原程序存档里，仍可能触发一次模型调用。** 插件将模型输入中的命令替换为“控制接口已处理”标记并要求不重复执行；无法保证模型绝不额外回话，也不能复现旧版“零模型调用”的入口。命令回复使用独立的限频队列，不能共用核心 `ctx.sender`（生命周期没有该对象）。这一差异仅影响专属命令，关系和恶作剧工具仍使用官方能力/工具接口。

若你的 OneBot 实现只允许单个 WebSocket 客户端，请关闭命令插件；其余关系/动作扩展仍可使用。连接失败会在日志中提示，每 5 秒检查配置并尝试重连；关闭插件会断开连接、清理等待请求和定时器。不要同时运行旧版核心里的 `/ds` 拦截和这个插件，否则可能重复响应。

## 验证与卸载

无第三方依赖。装有 Node.js 20+ 时，可在本包运行 `node --test test/*.test.mjs`。设置 `QQ_WHALE_UPSTREAM` 为 QQ Agent 源码目录可跑真实加载器集成测试；未提供源码时集成部分明确跳过。

在控制台关闭三份扩展即可停止功能；卸载时退出程序后移走 `plugins/whale-relations`、`plugins/whale-owner-controls` 与 `skills/whale-actions`，保留 `data/affection.json` 便于以后恢复。没有 QQ 登录态的本机测试只验证加载、持久化和模拟协议调用。工作笔记本用于先行验证真实群接口；正式部署和实际运行在服务器完成。
