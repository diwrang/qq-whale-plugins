# 小鲸鱼 · 个性签名 v1.0.0

让 QQ Agent 读取和修改机器人自己的 QQ 个性签名。按你的选择，默认允许自主修改，**每天最多2次，至少间隔12小时**；重启、热重载和重新安装后限额仍保留。

这是独立扩展，可以与之前的关系扩展、B站和QQ空间扩展一起使用。安装后在 **「技能」页**显示「小鲸鱼 · 个性签名」。

## 服务器安装

1. 把安装包传到服务器，在 QQ Agent 安装目录以外解压。
2. 完全退出 QQ Agent，包括右下角托盘。
3. 双击 **install-server.bat**，目标已固定为：

   `%LOCALAPPDATA%\Programs\QQ Agent`

4. 重新启动 QQ Agent，到 **「技能」页**确认「小鲸鱼 · 个性签名」已启用。新增3个工具：读取自己的个性签名、查看签名修改限额、修改自己的个性签名。

本地测试使用 `install.bat`，输入本地安装路径。安装器只安装 `skills\whale-signature`，不会修改以前的扩展、核心程序、配置和数据。重复安装会备份自身上一版；中文 JSON 读取兼容 Windows PowerShell 5.1。升级主程序后若扩展消失，重新运行安装器。

## 使用

可以直接对机器人说：

- 「看看你现在的个性签名。」
- 「把你的个性签名改成：事已至此，先吃饭吧。」
- 「你今天还能改几次签名？」

自主模式下，机器人可在新的心情或兴趣出现时选择换签名，不需要每次请示。行为由核心的聊天唤醒或主动机会触发，**不是每12小时固定换一次**。模型决定是否调用工具，核心工具总开关和聊天白名单仍需启用。

插件使用自己的保守上限：**非空、单行、最多80个字符**（按Unicode码点计数）。太长会明确拒绝，不会截断你的句子。此版不提供清空签名。

## 设置

在技能卡片的设置中，可调整：

- **签名修改方式**：自主修改 / 创建者要求时修改 / 关闭修改。
- **每天最多修改次数**：默认2，范围1–10，按北京时间计数。
- **修改至少间隔**：默认720分钟（12小时），最小10分钟。
- **创建者QQ**：默认留空，使用创建者请求模式前须填写有效 QQ 号。只在请求模式用于真实发送者身份判断；昵称和自称无效，本轮最后触发消息须来自创建者，由模型理解明确修改请求。

关闭修改后，读取和查看限额仍可使用。停用整份技能后，三个工具均不可用。

## 确认修改结果

写入使用 `set_self_longnick({longNick: ...})`，只修改当前登录的机器人账号；读取用 `get_stranger_info({user_id: 本人QQ})`，签名字段为 `long_nick`。接口已按 [SnowLuma v1.14.19 的动作源码](https://github.com/SnowLuma/SnowLuma/blob/v1.14.19/packages/onebot/src/actions/extended.ts) 和 [读取资料源码](https://github.com/SnowLuma/SnowLuma/blob/v1.14.19/packages/onebot/src/actions/friend.ts) 核对。

工具先读取当前签名。如果已是目标句子，就不写入、不占次数。需要修改时，先把预占记录写到数据目录，再发送一次修改请求，然后读取资料核验。

- **verified**：协议端读取资料的签名与新签名一致。
- **accepted**：协议端接受了修改请求，但暂时没读到新签名。QQ资料可能有缓存或延迟，不能说已核验成功。
- **uncertain**：请求超时或结果未知，可能已经改成功。先读取或查看 QQ 个人资料，不自动重试。

资料读取的网络请求失败时，SnowLuma可能回退缓存，因此核验表示「协议端返回资料与新签名一致」，不保证所有QQ客户端立即显示新值。详细处理见 [后端读取与缓存实现](https://github.com/SnowLuma/SnowLuma/blob/v1.14.19/packages/onebot/src/modules/contact-actions.ts)。

已发起的修改尝试都计入次数和冷却，包括失败或结果未知，避免重复改动。机器人在换会话、换文案、重启后也不能绕过限制。

## 数据与验证

默认服务器记录文件：

`%LOCALAPPDATA%\Programs\QQ Agent\data\whale-signature-state.json`

如设置了 `QQ_AGENT_DATA_DIR` 或多实例 `QQ_AGENT_PROFILE`，使用对应实例的数据目录。记录只包含账号、签名哈希、时间和状态，不存签名原文或登录密钥。损坏时停止修改，保留文件；读取功能仍可使用。不要删除记录来解除限频。两个独立实例登录同一QQ不共享计数。

18项测试通过，包含真实 QQ Agent 加载器、Windows PowerShell 安装、并发防重复、停用、重载、真实身份判断、账号切换、缓存和超时处理。QQ写入均使用模拟协议；没有实际改变你的服务器账号签名。

开发测试无需额外 npm 依赖：Node20以上，执行 `node --test test/*.test.mjs`。真实加载器测试还需设置 `QQ_WHALE_UPSTREAM` 为 QQ Agent 源码文件夹。
